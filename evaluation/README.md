# TenderMind: Genuine Retrieval Evaluation Pipeline

## 1. Overview & Research Context

This evaluation framework is designed for the final-year research project:
**"TenderMind: Intelligent Multi-Document Tender Analysis and Decision Support System"**
targeted for submission to an IEEE conference/transactions publication.

The pipeline performs an empirical, benchmark evaluation comparing three core retrieval strategies implemented in TenderMind:
1. **BM25 / Sparse Lexical Retrieval**: Scikit-learn TF-IDF vectorizer over cleaned document tokens with cosine similarity scoring.
2. **Dense Vector Retrieval (FAISS)**: Exact L2 Euclidean distance index (`faiss.IndexFlatL2`) using 384-dimensional dense semantic embeddings generated by `all-MiniLM-L6-v2` (`sentence-transformers`).
3. **Hybrid Retrieval**: Linear combination of min-max normalized dense and sparse similarity scores ($\alpha = 0.5$):
   $$\text{Score}_{\text{hybrid}} = \alpha \cdot \text{Score}_{\text{dense}} + (1 - \alpha) \cdot \text{Score}_{\text{sparse}}$$

All evaluations strictly reuse the **active production retrieval implementations** without mock logic or synthetic scores.

## 3. Evaluated Performance Metrics

For a given query $q$, retrieved top-$k$ chunk sequence $R_k = [c_1, c_2, \dots, c_k]$ ($k=5$), and verified ground-truth relevant chunk set $G$:

### 1. Precision@5
The fraction of top-5 retrieved chunks that are relevant:
$$\text{Precision@5} = \frac{|R_5 \cap G|}{5}$$

### 2. Recall@5
The proportion of all verified relevant chunks retrieved within the top 5:
$$\text{Recall@5} = \frac{|R_5 \cap G|}{|G|}$$

### 3. Mean Reciprocal Rank (MRR)
Measures how high the first relevant result appears in the ranked list. For a query $q$:
$$\text{RR}_q = \begin{cases} \frac{1}{\text{rank}(c^*)}, & \text{if } c^* \in R_5 \cap G \text{ is the highest-ranked relevant chunk} \\ 0, & \text{if } R_5 \cap G = \emptyset \end{cases}$$
$$\text{MRR} = \frac{1}{N} \sum_{q=1}^{N} \text{RR}_q$$

### 4. Hit Rate@5
Binary indicator whether at least one relevant chunk was retrieved in the top 5:
$$\text{Hit@5}_q = \begin{cases} 1, & \text{if } |R_5 \cap G| \ge 1 \\ 0, & \text{otherwise} \end{cases}$$
$$\text{Hit Rate@5} = \frac{1}{N} \sum_{q=1}^N \text{Hit@5}_q$$

### 5. Normalized Discounted Cumulative Gain (nDCG@5)
Evaluates ranking quality accounting for the graded/binary position of relevant items:
$$\text{DCG@5} = \sum_{i=1}^{5} \frac{\mathbb{I}(c_i \in G)}{\log_2(i + 1)}$$
$$\text{IDCG@5} = \sum_{i=1}^{\min(|G|, 5)} \frac{1}{\log_2(i + 1)}$$
$$\text{nDCG@5} = \begin{cases} \frac{\text{DCG@5}}{\text{IDCG@5}}, & \text{if } \text{IDCG@5} > 0 \\ 0, & \text{otherwise} \end{cases}$$

## 6. How to Run the Evaluation Pipeline

### Option A: Using the Existing Docker Environment (Recommended)

Run the evaluation script inside the active TenderMind backend container:
```powershell
docker exec tendermind-backend-1 python /evaluation/evaluate_retrieval.py
```

Regenerate the comparative performance graph:
```powershell
docker exec tendermind-backend-1 python /evaluation/plot_comparison.py
```

### Option B: Running Locally (Windows PowerShell)

If you have your local Python virtual environment activated with the dependencies from `backend/requirements.txt`:
```powershell
python evaluation/evaluate_retrieval.py
python evaluation/plot_comparison.py
```

## 7. Measured Experimental Results (Genuine Benchmark)

Evaluated across **15 verified test queries** spanning technical, legal, financial, and temporal tender dimensions:

| Retrieval Method | Precision@5 | Recall@5 | MRR | Hit Rate@5 | nDCG@5 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **BM25 (Sparse TF-IDF)** | **32.00%** | **76.11%** | **67.33%** | **86.67%** | **64.37%** |
| **Dense FAISS (all-MiniLM-L6-v2)** | **32.00%** | **71.11%** | **66.33%** | **80.00%** | **64.02%** |
| **Hybrid Retrieval ($\alpha=0.5$)** | **33.33%** | **73.33%** | **65.22%** | **80.00%** | **63.50%** |

### Key Experimental Insights for the Research Paper:
1. **Precision@5 Gains**: Hybrid retrieval yields a modest advantage in Precision@5 (33.33% vs. 32.00%), successfully fusing chunks retrieved by sparse and dense modalities (e.g. Q03, Q04) into the top-5 window.
2. **Sparse Lexical Resilience**: In specialized tender documents featuring alphanumeric identifiers (e.g., tender IDs, clause numbers, monetary amounts), BM25 achieves superior Hit Rate@5 (86.67%) and Recall@5 (76.11%) because exact token matching does not suffer from embedding semantic dispersion.
3. **Score Calibration Opportunity**: With naive equal weighting ($\alpha=0.5$), disparate score distributions between inverted Euclidean distance and TF-IDF cosine similarity can occasionally depress MRR (65.22%) compared to pure BM25 (67.33%), demonstrating the necessity of adaptive Reciprocal Rank Fusion (RRF) or query-dependent alpha tuning.
